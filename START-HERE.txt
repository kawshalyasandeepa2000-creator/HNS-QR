HOW TO UPLOAD TO GITHUB
-----------------------
1. Download and right-click the ZIP file -> Extract All.
2. Open the extracted folder -> docs (do not upload the whole outer folder).
3. Go to your EXISTING GitHub folder:
   https://github.com/kawshalyasandeepa2000-creator/HNS-QR/tree/main/docs
4. Choose Add file -> Upload files.
5. Upload ALL 10 files from this ZIP's docs folder into GitHub's EXISTING docs folder.
6. Click Commit changes (main branch).
7. Open GitHub Actions and wait for the Pages deployment green check.
8. Press Ctrl + Shift + R on your customer site and dashboard.
